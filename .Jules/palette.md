## 2024-06-30 - Accessible Form and Social Links
**Learning:** Even in static portfolio sites, basic accessibility like form labels and ARIA labels for icon-only links is often overlooked. Using a `.sr-only` class allows maintaining a clean visual design while providing necessary context for screen readers.
**Action:** Always include a `.sr-only` utility in global styles and ensure all interactive elements have descriptive names (via labels or ARIA).
